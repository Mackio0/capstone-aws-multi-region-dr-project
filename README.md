# AWS Multi-Region DR Capstone Project

**Simple To-Do web app built to demonstrate a multi-region disaster recovery (DR) architecture on AWS**

* PHP + Nginx (EC2)

* MySQL (RDS)

* Region-aware UI

* Infrastructure designed for failover scenarios

## TL;DR

**This is a minimal DR-ready web app:**

* Region-aware

* Auto-configuring

* Easy to deploy

* Built to demonstrate failover concepts, not production readiness
